# BLOODMONEY — Pedro Henrique Edition

Versão escolar e touch inspirada na estrutura de um clicker.

## Como jogar

- Toque no personagem Pedro Henrique.
- Cada toque gera dinheiro.
- Use o dinheiro para comprar upgrades.
- Os upgrades aumentam o valor recebido por toque.
- O objetivo é chegar a $25.000.
- O progresso é salvo no `localStorage`.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Pointer Events para toque
- localStorage

## Estrutura

- `index.html` — estrutura da interface
- `css/style.css` — visual
- `js/game.js` — lógica do jogo
